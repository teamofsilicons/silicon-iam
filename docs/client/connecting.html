A client is created once, at startup, and reused. Creating one performs a compatibility handshake that either agrees on an API major or returns no client at all.

Install

The package name uses a hyphen; Rust imports it with an underscore.

[dependencies]
silicon-iam = { path = "../iam-rust-library" }

The crate is not yet published to crates.io, so depend on it by path or by git revision. Pin a revision rather than tracking a branch: this client fails closed on a contract mismatch, and an unpinned dependency turns a backend deploy into an unplanned client upgrade.

The minimum supported Rust version is 1.88.

Credentials

An Application authenticates with its ID and secret, the pair issued once when it was registered. Both come from the environment or a secret store — never from source. 

use silicon_iam::prelude::*;

let credentials = ApplicationCredentials::new(
    std::env::var("SILICON_IAM_APP_ID")?,
    std::env::var("SILICON_IAM_APP_SECRET")?,
)?;

let client = Client::connect(credentials).await?;
assert_eq!(client.service_info().api_version(), ApiVersion::V1);

ApplicationCredentials redacts itself from Debug. Reaching the wire value requires an explicit expose_secret call, so a credential cannot reach a log line by accident.

The handshake

Client::connect always calls the unversioned GET /api/version first, advertising the majors this SDK implements: 

Silicon-IAM-Supported-API-Versions: v1

The server replies with the highest mutually supported version, its own catalog, and a Silicon-IAM-API-Version header. The SDK then verifies all of it before returning a client:

  • the service identifies itself as silicon-iam;
  • the advertised catalog is non-empty, bounded, well-formed, free of duplicates, and in descending order;
  • the selected version is exactly the highest version both sides support — not merely a version both support;
  • the response header agrees with the body.
It fails closed. If any of those checks fails, connect returns an error and no client exists. There is no degraded mode and no way to skip the handshake, because a client that guesses at the wire contract is a client that will eventually send a well-formed request that means something different from what its author intended.

Every later request is pinned to the negotiated major. The SDK builds its own paths from it, so an Application never writes /api/v1/… anywhere.

Choosing an origin

The default is https://backend.iam.teamofsilicons.com, exposed as silicon_iam::DEFAULT_BASE_URL. Override it through the builder: 

let client = Client::builder(credentials)
    .base_url("https://iam.staging.example.com")?
    .connect()
    .await?;

A custom origin must be HTTPS. Literal loopback HTTP has to be enabled explicitly, which keeps a local-development shortcut from surviving into a production configuration by accident.

Lifetime

Connect once and share the client. It owns a connection pool and the negotiated version, and reconnecting per request would repeat the handshake on every call for no benefit.

client.service_info() exposes the negotiated version, the server's advertised catalog, and its build and commit — useful in a health endpoint, and the first thing worth attaching to a bug report.
